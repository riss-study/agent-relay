---
name: join
description: 중계 서버에 참가한다(처음 또는 방 추가). 사용법은 /agent-relay:join <서버주소> <참가코드>
argument-hint: '<서버주소> <참가코드>'
---

사용자가 `/agent-relay:join <서버주소> <참가코드>` 를 실행했다.

1. 인자에서 서버 주소(예: `ws://10.0.1.23:8765`)와 참가 코드(`TR-…`)를 읽는다. 하나라도 없으면 형식을 안내하고 멈춘다.
2. `team_join` 을 `address`, `code` 로 호출하고 결과를 그대로 보여 준다.
3. 성공하면 다음부터는 세션을 켤 때 자동 접속된다고 알린다. 실패 문장에 "연결할 수 없습니다"가 있으면 주소에 스킴이 있는지와 서버 상태를 확인하라고 안내한다.
